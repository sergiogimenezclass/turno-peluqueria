# Sistema de Reserva de Turnos para Peluquería

Aplicación web para la gestión de turnos de una peluquería.

## Tecnologías

### Frontend
- HTML5
- CSS3
- JavaScript Vanilla

### Backend
- Python
- Flask

### Base de Datos
- SQLite

## Funcionalidades

### Reserva Pública
- Reserva de turnos online.
- Selección de servicio.
- Selección de fecha y horario.

### Administración
- Login de administrador.
- Gestión de servicios.
- Gestión de turnos.
- Agenda diaria.

## Instalación

```bash
git clone <repositorio>
cd peluqueria

python -m venv venv

source venv/bin/activate
# Linux

# o

venv\Scripts\activate
# Windows

pip install -r requirements.txt

python app.py
```
